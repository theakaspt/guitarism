## 3. 주요 고민 지점 & 결정

### 5-1. 철자를 "루트"가 아니라 "도수"로 정한다
예전 `noteName`은 루트가 ♭ 계열(F·B♭·E♭·A♭·D♭)이면 ♭ 배열, 아니면 ♯ 배열을 썼다. 그래서 C 마이너처럼 **루트는 ♯ 쪽인데 스케일은 ♭이 필요한 경우**가 전부 틀렸다.
새 함수는 "음 글자 = 루트 글자 + (도수 번호 − 1)"로 글자를 먼저 정하고, 실제 음높이와의 차이로 ♭·♯을 붙인다. 이러면 7음 스케일은 **글자 7개가 항상 서로 다르다**는 성질이 자동으로 지켜지고, 테스트도 그 성질 하나로 전수 검사할 수 있다.
`noteName`은 지우지 않았다(코드 사전 등 철자가 문제 안 되는 곳은 그대로).

### 5-2. 겹변화표(𝄫·𝄪)를 어디까지 허용하나
- **스케일:** 도수대로 쓰면 D♭ 내추럴 마이너가 `D♭ E♭ F♭ G♭ A♭ B𝄫 C♭`. 운영자 결정대로 이런 11건은 이명동음 루트(C♯ 등)로 철자하고 제목 옆에 "= C♯ 표기"를 붙인다. 휠의 루트 글자는 그대로.
- **코드:** A♯7의 3음은 교과서대로 C𝄪. 잼에서 B키·F♯키의 일부 코드에서만 나오고, 화면에는 "○○ 없음" 경고 문구에만 보인다.

### 5-3. 코드별 스케일 — 목록 대신 규칙 하나
예전: "m7이면 도리안 → 안 되면 다음 후보" 같은 코드 종류별 우선순위표. 코드가 키 안에서 몇 도인지 몰라서 vi·iii·IV에서 키 밖 음이 들어갔다.
지금: **"코드 루트에서 시작하는 7음 스케일 중, 코드 구성음을 다 포함하고 진행의 키 밖 음이 가장 적은 것"** 한 줄. 이 규칙이 ii=도리안, iii=프리지안, vi=에올리안, IV=리디안, V=믹솔리디안을 저절로 낸다. 마이너 V7만 예외로 기존(하모닉 마이너)을 유지 — 꿀팁 `jam.minor251`과 맞물려 있어서.
VI7(세컨더리 도미넌트)에 맞는 스케일이 앱에 없어서 **믹솔리디안 ♭13**(R 2 3 4 5 ♭6 ♭7, 멜로딕 마이너 5번째 모드)을 스케일 목록 **맨 끝**에 추가 — 저장된 스케일 번호가 밀리지 않게.

### 5-4. 코드 에이전트에 맡기면서 생긴 일
- 이 세션이 저장소 상위 폴더에서 열려 `.claude/agents/`의 전용 에이전트가 인식되지 않았다 → 같은 모델·지침으로 대신 실행

- 에이전트가 스스로 밝힌 규칙 위반: 읽기 전용 `git status` 1회, 자기가 만든 임시 테스트 파일 1개 삭제. 남은 임시 파일 1개는 `../_to_delete/2026-11-22/`로 옮김

## 5. 검증 방법론 (이번 세션 추가분)

- **(U) 성질로 하는 철자 전수 검사.** 정답표를 만들지 않고 "7음 스케일이면 글자 7개가 모두 다르다 / 이름의 음높이 = 실제 음높이 / 겹변화표 없음"이라는 성질을 전 스케일×12루트에 건다. 정답표는 틀리게 만들 수 있지만 성질은 그렇지 않다. 대표 예시 몇 개는 회귀용으로 따로 고정.
- **(V) 키 밖 음 개수로 하는 코드-스케일 검사.** "이 코드엔 이 스케일"을 외워 넣지 않고, 각 추천 스케일이 진행의 키 밖 음을 몇 개 품는지 센다. 0이 아니면 실패.
- **(W) 실화면 확인을 검수 전에.** 자동 테스트가 다 통과한 상태에서 실제 앱을 375px로 띄워 보다가 #24를 찾았다. 렌더 테스트의 "E♭이 화면에 있다"는 단언은 루트 휠에도 E♭이 있어서 **수정 전에도 통과하는 약한 단언**이었다(검수 지적) → 지판 SVG 안 라벨만 따로 확인하도록 보강.

## 6. 알려진 한계 / 리스크 (갱신)

- **𝄪(겹올림표) 글자가 아이폰에서 제대로 보이는지 확인 못 함.** 맥 크롬에서는 보인다. 깨지면 네모로 보인다. 나오는 곳은 "○○ 없음" 경고 문구뿐(B·F♯ 키 일부)
- **스케일 화면 제목·휠은 여전히 `ROOTS` 표기.** 예: F♯키에서 "D♯ 내추럴 마이너 보기"를 누르면 제목은 "E♭ 내추럴 마이너"로 뜬다(같은 음, 다른 이름). 휠이 D♯/E♭을 구분하지 못하는 구조라 이번 범위 밖
- 겹변화표가 없으면 전환하지 않으므로 A♭ 내추럴 마이너는 ♭ 7개(C♭·F♭ 포함)로 표기된다. 이론상 맞는 표기지만 실전에선 G♯ 마이너로 더 많이 부른다
- 잼 보이싱 지판의 `note` 값은 원래 화면에 쓰이지 않는다(원 안은 도수). 이번엔 건드리지 않음

## 8. 운영자 확인 체크리스트 (폰을 들고 순서대로)
